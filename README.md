# ⚡ Nexus Hub (NH)

## 📌 Overview

**Nexus Hub (NH)** is a modular Roblox scripting framework built for creating flexible in-game tools, UI systems, and feature modules.  
It is designed with performance, organization, and customization in mind, allowing developers to easily expand functionality across different experiences.

---

## ✨ Features

- 🧩 Modular system architecture
- 🎛️ Custom UI framework (Black / Red theme)
- 🔘 Toggles, sliders, and dropdown support
- ⚙️ Config-based settings system
- 📦 Easy feature expansion via modules
- 🚀 Lightweight and optimized structure
- 🎨 Clean and modern interface design
- 🔄 Fully customizable layout system

---

## 🎮 Supported Games

Nexus Hub is designed to be adaptable across multiple Roblox experiences, including:

- Football Fusion 2 (FF2)
- Brookhaven 🏡
- Basketball Legends (BSL)
- Additional games can be added via modules

## 🎛️ UI System

The Nexus Hub interface includes:

* Sidebar navigation
* Feature tabs
* Toggle controls
* Adjustable sliders
* Dropdown selectors
* Real-time configuration updates

All UI elements are designed for smooth interaction and minimal performance impact.
